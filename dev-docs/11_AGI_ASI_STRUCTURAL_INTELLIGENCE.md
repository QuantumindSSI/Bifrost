### The frequency hierarchy of cognition

Biological systems use a frequency hierarchy for different levels of semantic processing:

| Frequency band | Cognitive function | Semantic level |
|---|---|---|
| Delta (1-3 Hz) | Global discourse structure | Discourse/narrative |
| Theta (4-8 Hz) | Cross-modal associations, memory encoding | Word/phrase |
| Alpha (8-12 Hz) | Gating, inhibition, top-down control | Attention |
| Beta (13-30 Hz) | Cognitive control, maintenance | Executive |
| Gamma (30-80 Hz) | Local feature binding, conscious perception | Feature/object |

**This is directly analogous to the MSC framework's multi-scale structure**: different scales (modulation frequencies) capture different levels of semantic structure. CBMPC's modulation frequencies (0.5-32 Hz) span the delta, theta, alpha, and beta ranges — exactly the frequencies implicated in semantic processing.

### Phase 2: Cross-modal structural intelligence

**Goal**: Demonstrate that MSC embeddings from different modalities can be aligned for cross-modal retrieval and structural similarity assessment.

**Pre-registered hypotheses**:

1. Encode logical rules as phase relationships in the frequency domain

3. Use cross-frequency coupling for hierarchical reasoning
4. Implement spectral rule grounding via phase locking

### Phase 6: AGI via structural resonance

**Goal**: Achieve general intelligence through structured resonance — phase-locked coherence across modalities, scales, and cognitive levels.

**Thesis**: Intelligence is not pattern matching. Intelligence is the ability to discover, maintain, and manipulate phase-coherent structure across multiple scales and modalities. This is what biological brains do (via neural oscillations and phase synchronization), and it is what Bifrost aims to implement computationally.

## The five priority research directions

Based on the synthesis of all evidence, the five most promising research directions for Bifrost are:

### 1. Frequency-domain semantic architecture (highest priority)

Implement semantic structure as phase-locked coherence across frequency bands, with frequency-band-specific channels for different semantic levels (delta for discourse, theta for words, gamma for features).

**Why**: This is the direct implementation of the Bifrost thesis, supported by both the CBMPC validation and the biological neuroscience evidence.

### 2. Spectral neuro-symbolic reasoning

Integrate symbolic reasoning with spectral representations, performing inference via phase alignment in the frequency domain.

**Why**: This bridges the neural/symbolic divide using the common language of frequency and phase, supported by emerging work in spectral NSR (arXiv:2509.07017).

### 3. Phase-based cross-modal binding

Implement phase synchronization for cross-modal semantic structure, inspired by biological cross-modal integration.

**Why**: Biological systems use phase synchronization for cross-modal binding (Nat Comm 2019). This is the mechanism for the MSC framework's cross-modal alignment.

### 4. Recursive spectral self-improvement

Enable recursive structural improvement via spectral methods, using phase coherence metrics to identify and fix structural weaknesses.

**Why**: This is the path to ASI — recursive self-improvement is the core ASI capability, and spectral methods provide the structural language for self-modification.

### 5. Spectral world models

Build structured world models using object-centric spectral representations, with dynamics learned via spectral evolution.

**Why**: World models are necessary for planning and reasoning. Spectral world models would capture structure in a way that enables compositional generalization.
